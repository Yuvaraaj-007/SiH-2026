# SiH-2026 – Autonomous Robotic Inspection of Hazardous Zones of chemical industries

This repository contains the solution overview for our Smart India Hackathon (SiH) 2026 submission under the **Open Innovation – Software and Hardware** category.

**Idea Title:** Autonomous Industrial Patrol Robot
  

## 📦 How to View the Solution

1. Download **`Overview of solution.zip`** from this repository.
2. Extract/unzip it on your system:
   - **Windows:** Right-click the file → *Extract All*
   - **Mac:** Double-click the `.zip` file
   - **Linux:** Run `unzip "Overview of solution.zip"`
3. Open the extracted **`Overview of solution`** folder — it contains all design, hardware, and electrical documentation described below.
